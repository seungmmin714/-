# MOA 0.1.0 MVP

휴게·충전 중 질문을 꺼내고, 사실 설명과 선택형 이야기를 거쳐 가족 대화로 이어지는 Android 앱입니다.

## 설치

첨부된 `MOA-0.1.0-demo.apk`를 Android 9 이상 일반 Android 기기에 설치하세요. 첫 화면에서 **시연 모드 시작 → 보호자와 함께 시작하기**를 누릅니다. 개발용 APK이며 실제 차량의 주행 상태·조명을 흉내 낸 제어 신호를 보내지 않습니다.

## 포함 기능

- 질문 카드 10개, 카드 검색, 질문 직접 입력, 지원 기기의 기기 내 음성 입력
- 고정 사실 설명, 최대 2회의 확인, 범위 밖 질문의 가족 전달
- 소재 10개와 4가지 선택 경로, 사실/상상 구분, 바다·숲·별빛 테마
- 직접 눌러 재생하는 읽어주기와 짧은 테마 소리
- 질문·실제 선택·열린 질문이 담긴 가족 카드, 명시적 저장과 보관함 삭제
- 중단·수동 재개·종료, 주행 제한/연결 손실 시연

## 연동 범위

실제 AAOS 제한 상태 구독 코드를 포함하지만 실제 Pleos/차량 검증은 남아 있습니다. 차량 Light와 외부 AI는 연결하지 않았습니다. 테마는 화면에 적용하며, 음성은 설치된 한국어 오프라인 엔진과 모델이 있는 기기에서만 가능합니다. 카드·텍스트로는 네트워크 없이 전체 흐름을 완료할 수 있습니다.

자동 저장은 꺼져 있습니다. 보호자가 직접 저장한 최근 100개 카드만 앱 내부에 남으며, 세션 종료 시 현재 질문과 선택은 삭제합니다.

검증: 단위 테스트 19개와 UI 테스트 4개(가로·세로 각각) 통과, Debug/Release 빌드 성공, lint 오류 0개. APK의 SHA-256 파일을 함께 제공합니다.
