# MVP 검증 시나리오

이 문서는 실제 구현의 확인 기준이다. 실제 차량의 조명 반영, Pleos 인증 또는 사용자 효과 검증을 의미하지 않는다.

## 기본 여행

1. 개발용 APK를 일반 Android 기기에 실행한다. 최초 상태는 미확인이고 놀이가 자동 시작되지 않는다.
2. 보호자가 명시적으로 시연 모드를 선택하고 시작한다.
3. 구름 카드를 선택한다. 고정 설명과 ‘사실 설명’ 표시를 확인한다.
4. 상상 이야기 시작을 누른다. ‘상상 이야기’ 구분을 확인한다.
5. 바다 → 친구에게 인사를 선택한다. 두 번만 선택하며 이야기가 완결된다.
6. 가족 카드에 원래 질문·실제로 고른 두 선택·열린 질문 하나만 나타난다.
7. 저장하지 않고 종료한다. 현재 질문과 선택은 지워지고 보관함에 추가되지 않는다.

## 입력과 예외

- `구름은 왜 움직여?`: 구름 설명으로 연결한다.
- `구름의 무게는 얼마야?`: 단어가 같다는 이유만으로 움직임 설명을 정답처럼 제공하지 않는다.
- 모호한 질문을 세 번 제출: 최대 두 번의 확인 후 가족과 알아볼 질문으로 넘긴다.
- 확인 안내를 받은 뒤 질문을 수정하고 가족에게 넘기면 입력란의 최신 문장이 카드에 담긴다. 빈 입력으로는 넘길 수 없다.
- 빈 입력·길이 제한·잘못된 카드 ID·잘못된 분기 ID를 처리한다.
- 음성 서비스/한국어 오프라인 음성/마이크 권한이 없어도 카드와 텍스트로 진행한다.
- 온라인 AI 호출이나 원본 음성 파일 저장이 발생하지 않는다.

## 보호자·중단·복원

- FACT, STORY, ENDING, FAMILY 각각에서 제한 상태로 전환하면 PAUSED로 바뀐다.
- 중단 시 음성·효과음을 멈추고 화면 테마를 기본으로 돌린다.
- 제한이 풀려도 보호자가 재개하기 전에는 내용·음성이 다시 나오지 않는다.
- 앱이 배경으로 이동하면 멈춘다. 다시 열어도 자동 재생하지 않는다.
- 질문 입력 중 중단한 뒤 수동 재개하면 제출 전 초안과 기존 확인 안내·확인 횟수가 유지된다. 중단 화면에서는 초안이 보이지 않는다.
- 종료 후 새 여행을 시작하면 이전 질문 초안이 없어야 한다. 화면 재생성·프로세스 종료 후에는 복원하지 않는다.
- 중단 중에는 저장·주제 선택·설정의 우회로가 없어야 한다.
- 자동차 기기와 release 빌드에서는 시연 상태로 실제 제한을 덮어쓸 수 없다.
- 연결 실패·연결 끊김·현재 상태 미확인은 모두 UNKNOWN으로 처리한다.
- 종료는 제한 여부와 관계없이 가능하며 메모리의 세션을 삭제한다.

## 저장

- 저장 버튼을 누른 경우만 앱 내부에 카드가 기록된다.
- 앱 재실행 후 명시 저장한 카드만 확인한다.
- 개별 삭제와 전체 삭제를 확인한다.
- 원본 음성·위치·아동의 이유/감정/성격 추정치를 저장하지 않는다.
- 클라우드 백업·기기 이전 백업에서 앱 데이터를 제외한다.
- 저장 실패 시 성공했다고 표시하지 않는다.
- 보관함 파일 손상·지원하지 않는 형식·읽기 오류는 빈 보관함과 구분하여 안내한다. 다시 불러오기가 실패해도 기존 파일을 덮어쓰지 않는다.
- 일부 카드만 손상되면 읽을 수 있는 카드는 보여 주되, 저장·개별 삭제는 기존 데이터를 덮어쓰지 않고 실패한다.
- 보관함 오류에서도 전체 삭제를 요청할 수 있다. 확인을 취소하면 파일이 남고, 명시적으로 확인하면 빈 보관함으로 새로 시작한다.

## 실제 Pleos 확인이 필요한 항목

- Pleos 2.1.0의 제한 이벤트·앱 잠금·수동 재개 확인 완료. 실제 차량과 서비스 재시작·연결 손실 처리는 추가 확인.
- 설치된 기기 내 한국어 음성 엔진의 지원 여부.
- Vehicle Light SDK capability·권한·원래 값 조회·적용 후 재조회·복원.
- 공모전 배포 규격, 서명 및 플랫폼 심사.

현재 일반 Android 에뮬레이터의 통과 결과는 실제 차량 연동 검증을 대신하지 않는다.
