# 모아 MVP 시연

일반 Android 기기 또는 에뮬레이터에 `app-debug.apk`를 설치합니다. 네트워크 연결 없이 카드·이야기·보관함 흐름을 확인할 수 있습니다. 음성은 해당 기기에 설치된 오프라인 엔진과 한국어 모델에 따라 달라집니다.

## 기본 여행

1. **시연 모드 시작**을 누릅니다. 개발용 시연 표시와 실제 차량 제어가 없다는 안내를 확인합니다.
2. **보호자와 함께 시작하기**를 누릅니다.
3. 카드에서 **구름은 왜 움직여?**를 선택합니다. 카드 검색에 `구름`을 입력하거나 직접 질문을 적어도 됩니다.
4. **사실 설명** 표시와 고정 설명을 읽습니다. 지원 기기에서는 **설명 읽어 주기**를 눌러 음성으로 듣습니다.
5. **구름 이야기 시작하기**를 누릅니다. **상상 이야기** 표시로 사실과 창작이 분리되는지 확인합니다.
6. **바다로 갈래 → 새 친구에게 인사할래**를 선택합니다. 다른 선택 조합도 각각 짧은 결말로 이어집니다.
7. 마지막 이야기를 확인하고 **가족 대화 카드 보기**를 누릅니다.
8. 질문, 실제 두 번의 선택, **구름을 타고 어디에 가보고 싶어?**가 표시되는지 확인합니다.
9. **보호자가 이 카드 저장하기**를 누른 뒤 **오늘의 여행 마치기**를 누릅니다.
10. **보관함 → 카드 열기**로 내용을 확인합니다. 개별 삭제와 전체 삭제에는 확인 단계가 있습니다.

저장을 누르지 않고 마치면 새 카드가 보관함에 생기지 않습니다. 저장한 카드만 앱을 다시 실행한 뒤에도 남습니다. 보관함은 최근 100개를 유지합니다.

## 질문을 모를 때

질문 입력에 `구름 무게는 얼마야?`를 적어 **질문 확인**을 누릅니다. 모아는 ‘구름’이라는 단어만 보고 움직임에 대한 설명으로 답하지 않습니다.

- 최대 두 번 질문을 확인합니다. 제안한 기존 질문이 맞으면 해당 카드를 직접 선택할 수 있습니다.
- 같은 범위 밖 질문을 세 번째 제출하면 가족과 함께 알아볼 카드로 넘어갑니다.
- 바로 넘기려면 **가족과 함께 알아볼 질문으로 남기기**를 누릅니다.
- 가족 카드에는 만들어 낸 설명이나 이야기 선택 기록이 없습니다.

## 중단과 재개

이야기 진행 중 상단 개발용 시연 패널에서 **주행 제한**을 누릅니다. 화면·소리가 중단되고 내용 대신 일시정지 화면이 보여야 합니다.

1. **허용**을 눌러도 자동으로 이야기가 이어지지 않는지 확인합니다.
2. **보호자가 다시 시작하기**를 눌러 이전 단계로 돌아갑니다.
3. **연결 끊김**에서도 같은 중단 동작을 확인합니다.
4. 홈 화면으로 앱을 내렸다 돌아오면 보호자가 직접 재개해야 합니다.
5. 중단 상태에서 **여기서 마치기**를 누르면 현재 세션이 삭제됩니다.

시연 버튼은 일반 기기의 디버그 빌드에만 있습니다. 실제 Automotive 기기에서는 실제 플랫폼 상태를 사용하며, 릴리스에는 시연 우회가 없습니다. 이 절차는 실제 차량 연동 검증을 대체하지 않습니다.

## 테마와 음성

- 이야기 화면에서 **바다·숲·별빛**을 바꾸면 화면의 배경이 달라집니다. 차량 조명 미연결 표시를 확인합니다.
- **테마 소리 듣기**는 짧은 로컬 소리를 한 번 재생합니다. 반복·자동 재생이나 시스템 볼륨 변경은 없습니다.
- **이야기 읽어 주기**, **말로 질문**은 사용자가 눌렀을 때만 동작합니다.
- 오프라인 음성을 사용할 수 없는 기기는 안내 후 카드·화면 읽기로 계속 진행합니다.
- 음성 권한을 거절해도 카드와 직접 입력을 사용할 수 있습니다. 권한 창을 다녀오며 일시정지되면 보호자가 재개한 뒤 다시 음성 버튼을 누릅니다.

현재 세션은 메모리에서만 유지하므로 화면 재생성·프로세스 종료 후 이어서 복구되지 않습니다. 실제 Pleos 주행 제한·차량 조명·Pleos 전용 음성 검증 범위는 [연동 문서](PLEOS_INTEGRATION.md)를 참고하세요.
