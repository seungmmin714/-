# 질문 카드 내용 검토

확인일: 2026-11-13 · 대상: `core/src/main/kotlin/ai/moa/core/Content.kt`의 고정 설명 10개.

공공 과학·기상 기관의 아래 원문을 확인하고, 카드의 핵심 설명과 대조했다. 이는 개발 단계의 출처 검토이며 아동 대상 이해도 시험이나 교육 전문가 인증은 아니다. 앱 문장은 짧은 자체 한국어 설명이고, 아래 자료의 장문 인용·이미지는 포함하지 않았다.

| 카드 | 확인한 내용과 단순화 범위 | 확인 자료 |
| --- | --- | --- |
| 구름 | 구름은 작은 물방울 또는 얼음 입자이며 공기의 흐름과 함께 이동한다. 모든 구름이 동일하게 움직인다는 뜻은 아니며, 정체해 보이는 산악파 구름 같은 예외는 설명 범위 밖이다. | [Met Office: Clouds](https://weather.metoffice.gov.uk/learn-about/weather/types-of-weather/clouds), [NOAA: Clouds](https://www.nesdis.noaa.gov/our-environment/clouds) |
| 비 | 작은 물방울의 충돌·합체로 커진 방울이 떨어지는 과정을 설명한다. 얼음 결정이 성장한 뒤 녹아 내리는 다른 생성 경로도 있다. | [NOAA: Atmospheric Collisions](https://www.noaa.gov/jetstream/global/learning-lesson-atmospheric-collisions) |
| 무지개 | 햇빛의 여러 색이 물방울에서 굴절·내부 반사되며 나뉘어 보인다. 물방울의 출입 시 굴절을 간단히 묶어 설명했다. | [뉴질랜드 MetService: Rainbows](https://about.metservice.com/learning/rainbows) |
| 산 | 판의 충돌·압축에 따른 융기와 분출 물질의 축적으로 산이 만들어지는 대표 경로를 제시한다. 특정 산의 형성 원인이나 모든 산의 기원을 판별하지 않는다. | [USGS: Mountain-building 설명](https://www.usgs.gov/educational-resources/whats-new-weeks-9-12), [USGS: About Volcanoes](https://www.usgs.gov/programs/VHP/about-volcanoes) |
| 강 | 중력 때문에 물이 높은 곳에서 낮은 곳으로 흐른다. 국소적인 역류·조석·인공 수로는 설명 범위 밖이다. | [USGS: Rivers, Streams, and Creeks](https://www.usgs.gov/water-science-school/science/rivers-streams-and-creeks) |
| 바다 | 육지 암석에서 녹아 나온 이온이 하천을 통해 바다에 공급되는 경로를 설명한다. 해저 열수·화산 등도 공급원이며, 카드가 모든 공급원을 열거하지는 않는다. | [NOAA: Why is the ocean salty?](https://oceanservice.noaa.gov/facts/whysalty.html) |
| 나무 | 광합성은 햇빛 에너지로 물과 이산화탄소를 이용해 당을 만드는 과정이다. 나무의 생장에는 물·빛 외에도 무기 양분 등 조건이 필요하다. | [NASA: The Carbon Cycle](https://science.nasa.gov/earth/earth-observatory/the-carbon-cycle/) |
| 바람 | 태양의 불균등 가열과 기압 차이가 공기의 이동을 만든다. 지구 자전·마찰·지형 등 바람의 방향과 세기를 바꾸는 요소는 생략했다. | [EIA: Wind explained](https://www.eia.gov/energyexplained/wind/index.php), [Met Office: Wind](https://weather.metoffice.gov.uk/learn-about/weather/types-of-weather/wind) |
| 달 | 눈에 보이는 달빛은 달 표면이 반사한 태양빛이다. | [NASA: Moonlight](https://science.nasa.gov/moon/moonlight/) |
| 별 | 별빛이 움직이고 불균일한 지구 대기를 지나면서 방향이 변해 반짝여 보인다. 별 자체의 장기적인 밝기 변화와는 구분한다. | [NASA: Why Stars Twinkle](https://science.nasa.gov/image-article/apod-2000-july-25-why-stars-twinkle/) |

## 콘텐츠 변경 시 확인

- 사실 설명은 고정 카드에서만 제공한다. 소재 단어가 같다는 이유만으로 다른 질문의 답으로 사용하지 않는다.
- 이야기로 넘어갈 때 `상상 이야기`를 표시한다. 말하는 구름·조개 등 의인화는 사실 설명이 아니다.
- 가족 카드에는 질문과 실제 선택을 기록한다. 아이의 마음·이유·성격을 추정하거나 채점하지 않는다.
- 현지 건물·산·날씨·현재 위치를 알아본 듯한 설명을 추가하지 않는다.
- 문장이나 별칭을 바꾸면 해당 출처와 질문의 의미를 다시 확인하고, 사실/창작 구분 및 범위 밖 질문 테스트를 다시 실행한다.

초기 문장 길이·어휘·동반 이용 시간의 적합성은 보호자와 아동의 실제 사용성 테스트에서 별도로 확인해야 한다.
